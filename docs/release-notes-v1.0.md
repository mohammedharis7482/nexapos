# NexaPOS v1.0 release notes

NexaPOS v1.0 provides shop registration/onboarding, Shop ID session login,
owner/cashier accounts, direct team creation, catalogue/CSV import, inventory,
shifts, billing, cash and external-terminal card recording, held bills,
receipts, sales, reports, settings, and responsive role-aware navigation.

Release hardening removed subscription-seat and unfinished invitation UI,
clarified the account maximum as a system safety limit, made the frontend
production API URL mandatory, added safe request-completion logging, and
documented deployment, backup, rollback, smoke testing, and limitations.

No payment gateway, supplier/purchasing, subscription checkout, accounting,
loyalty, payroll, or multi-branch capability is included.
