# Core POS scope

NexaPOS covers one shop's accounts, catalogue, inventory, shifts, billing,
external-terminal payment recording, receipts, sales, reports, and operational
exports. It deliberately excludes payment gateways, subscriptions and
recurring billing, suppliers/purchases, loyalty, payroll, accounting, and
multi-branch management.

Navigation groups the existing scope without changing it: drawer shifts are
under Sales, team administration is under Settings, and product import remains
available both from Products and owner-only Data Management. No calculation,
tenant boundary, or API authorization is altered by this organization.
